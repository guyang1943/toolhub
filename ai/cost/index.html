AI 要花多少钱

这一页没有价格表。价格是周级变化的东西，抄一次就错一次；这里给公式、三个反直觉点和一个换算器，单价你自己填，或者用核对过日期的那几个默认值。

先记住这一条公式

成本 = 输入 tokens × 输入单价 + 输出 tokens × 输出单价

看起来平平无奇，但三件让人意外的事全藏在这三个乘号里。另外，token 不等于字数： 中文大约 1 个字 ≈ 0.6–1 个 token，各家分词器不一样；英文大约 1 个词 ≈ 1.3 个 token。 想知道你那段话到底多少 token，用 站内的 token 计数器量一下最快。

三个反直觉的点

  1. 输出比输入贵，而且贵得不少。按 DeepSeek 的公开价，输入 $0.15 / 输出 $0.60（每百万 token， 空闲时段）——4 倍。也就是说，让模型「详细说说」比「读你几千字」更容易把账单推上去。
  2. 推理模型的思考 token 按输出计费。它先想一段再回答，想的那段也是钱，而且常常比答案还长。 同一条问题，「思考模式」的账单可以是普通模式的几倍——这不是它偷偷多收，是它真的输出了那些 token。
  3. 命中缓存能便宜一个数量级。同一个模型：缓存命中 $0.003，未命中 $0.15——差 50 倍。 所以系统提示词、长文档前缀、同一个文件的第二轮追问，都应该尽量复用，而不是每轮重新粘贴。

还有一条不算反直觉，但比上面三条更贵：峰谷差。DeepSeek 的高峰时段单价是空闲时段的两倍， 而高峰只占工作日的一小段。批量任务挪到夜里跑，账单直接砍半——这一条不需要改任何代码。

如果输入里 80% 能命中缓存，月账单约 $3.65（省 39%）——靠的是把前缀固定住。

省钱的三件事，按性价比排

  1. 先把要问的东西问清楚。一次问不明白、来回五轮，比单价贵五倍更伤。这一条不花钱，只花几分钟。
  2. 复用前缀。系统提示词、长文档、同一份代码，放在每轮对话的开头并保持不变，命中缓存就是 50 倍差价。
  3. 把批量活挪到空闲时段。不需要改代码，只需要改运行时间。

反过来，最不值的三件事：为了省 token 把问题写得含含糊糊（换来更多轮）、拿便宜模型硬做它做不了的事 （换来重做）、以及「先买年付套餐再想需求」。

这一页不做什么

不预测你会用多少、不替你选模型、也不做「哪家最便宜」的排行榜——那要每周重排一次，排完还是会被调价打脸。 这里的立场很简单：算法是稳的，数字是变的。所以给你算法和入口，数字你自己填。
