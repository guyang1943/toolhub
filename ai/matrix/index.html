这张表怎么读

  • ✓ 官方文档明确写了支持。
  • ✕ 官方文档明确写了不支持，或给出了完整特性清单而它不在其中。
  • ? 官方文档没说，或者我没找到依据。它不是「不支持」——很多能力是文档没提，而不是没有。宁可留一个问号，也不替厂商下结论。

一处口径要说清：MCP 服务端没有「订阅」这回事。要你自己带 token 或数据库地址的，「自带 Key」记 ✓；完全不需要凭据的记 ?,那是因为这个问题对它不成立，而不是它不支持。

七项属性各问一件事：MCP（能接 Model Context Protocol——作为客户端或服务端，有配置入口）；本地模型（能连本地模型或自托管端点，而不是只能用厂商云）；自带 Key（可自带 API key 或第三方兼容端点，不被官方订阅绑死）；开源（源码公开，且有开源许可证）；免费档（有能用的免费档、免费额度或完全免费）；多代理（支持多个子代理并行或委派，而不只是单轮问答）；无界面（可非交互运行（CLI 参数 / 服务模式 / 可脚本化批量调用））。

这张表回答的是「文档承诺了什么」，不是「用起来好不好」。能力属性大约按季度变化，所以每条都带核对日期和官方出处；价格和型号变化快得多，这里一个字都不写——那种表上线两周就开始撒谎。

这张表不做什么

不做价格表，不做跑分榜，也不做「收录 500 个」清单。价格与型号是周级变化，抄一次就错一次；跑分不等于你的任务；收录量是别人更新更快的地方。这里只留变化慢、且能被官方文档核对的东西。

也不替你选。同一行里「开源 ✓、免费档 ✕」是好是坏，取决于你是要省钱还是要能改源码——这张表的用处是让你在掏钱或交数据之前，先看见自己在选什么。

数据源：assets/data/ai-matrix.json，构建期校验——缺出处、日期非法、七项没逐项表态，任何一条都会让构建失败。本页最老的一条核于 2026-11-28。
