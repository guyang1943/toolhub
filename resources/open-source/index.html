值得收藏的开源项目清单

帮你持续发现优质开源项目的渠道，比漫无目的刷 Trending 高效

合集导语

「怎么找到好项目」往往比「怎么写代码」更影响成长速度。这里收的是发现渠道而不是项目本身：有中文社区的人工精选（HelloGitHub、阮一峰周刊），有数据驱动的榜单（OSS Insight、Trendshift），也有按领域查找同类库的工具（LibHunt）。建议订阅 1-2 个精选渠道，其余按需查找——订阅太多反而会变成信息噪音。

怎么选

  • 想每周固定看一批新项目：订阅 HelloGitHub 或阮一峰周刊
  • 要按领域找同类库并比较：用 LibHunt
  • 想看数据驱动的趋势榜：Trendshift 或 OSS Insight
  • 国内网络访问 GitHub 慢：用 GitCode 镜像或 Gitee 探索

全部来源

HelloGitHub

中文开源项目月刊，按「入门级/工具/实战」分类，每条都有人工写的推荐理由，是目前最适合中文开发者的发现渠道。

授权：免费阅读 · 来源：HelloGitHub 团队 · 访问 ↗

阮一峰的网络日志

《科技爱好者周刊》每期精选几十条技术资讯与开源项目，中文技术圈影响力最大的个人博客之一，信息密度高。

授权：免费阅读（版权归作者） · 来源：阮一峰 · 访问 ↗

OSS Insight

用 GitHub 公开数据做分析：可以查某个语言最活跃的仓库、某个项目近三年的提交趋势，判断项目是否健康比看 Star 数可靠。

授权：开源（可自部署） · 来源：PingCAP · 访问 ↗

Trendshift

GitHub 趋势榜的增强版，能按语言、时间维度筛选，还保留了历史榜单；比官方 trending 页信息更全。

授权：免费浏览 · 来源：trendshift.io · 访问 ↗

LibHunt

按语言与领域列出开源库，并把同类项目并列对比（Star 走势、活跃度、替代方案），选依赖时很有用。

授权：免费浏览 · 来源：libhunt.com · 访问 ↗

开源中国

国内老牌开源社区，开源资讯与项目库都有；适合快速了解国内开源生态在做什么。

授权：免费浏览 · 来源：OSChina · 访问 ↗

Gitee 开源探索

国内代码托管平台的探索页，能找到大量中文文档齐全的项目，国内部署与访问也更方便。

授权：免费浏览 · 来源：Gitee · 访问 ↗

GitCode

GitHub 仓库的国内镜像与加速服务，拉取热门开源项目比直连 GitHub 稳定得多，适合国内网络环境。

授权：免费使用 · 来源：GitCode（CSDN） · 访问 ↗
