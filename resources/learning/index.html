学习路线与免费课程

从入门到进阶的免费学习资源，含路线图、公开课与中文教程

合集导语

碎片化地看教程，最大的问题是不知道「下一步该学什么」。这里收的资源分两类：一类给方向（路线图、周刊、名校公开课），一类给练习（交互式课程、编程题库）。建议的用法是——先用路线图确定学习顺序，再用交互式课程把基础打牢，最后用真实项目练手。注意：这些站点的免费范围各不相同，有的是全部免费，有的是免费旁听不发证书，报名付费前先看清楚。

怎么选

  • 不知道学什么顺序：先看 roadmap.sh 的对应方向路线图
  • 想边学边写代码：freeCodeCamp 或 Exercism（有反馈）
  • 查具体 API 用法：MDN（Web）与菜鸟教程（中文速查）
  • 想系统补计算机基础：CS50 或中国大学 MOOC

roadmap.sh

前端、后端、DevOps、AI 等方向的技能路线图，节点极细，能清楚看到「学完这个再学什么」，避免东一榔头西一棒子。

freeCodeCamp

完全免费的交互式编程课程，边写代码边过关，从 HTML 到机器学习都有；不收费也不发付费证书，纯粹靠捐赠运营。

授权：免费（内容 CC-BY-SA，非营利） · 来源：freeCodeCamp.org · 访问 ↗

MDN Web Docs

Web 技术的权威文档，HTML/CSS/JavaScript 的每个 API 都有示例和浏览器兼容表；查「这个属性到底怎么用」时比搜索引擎可靠。

授权：免费（内容 CC-BY-SA 2.5） · 来源：Mozilla · 访问 ↗

廖雪峰的官方网站

中文技术教程的经典，Python、Java、Git、JavaScript 都有完整体系，讲解从原理出发、例子能直接跑，适合系统入门。

授权：免费阅读（版权归作者，禁止转载） · 来源：廖雪峰 · 访问 ↗

CS50

哈佛的计算机科学导论课，讲 C、Python、SQL 与算法，作业质量极高；免费旁听全部课程与讲义，是补基础最好的公开课之一。

授权：免费旁听（课程内容版权归 Harvard） · 来源：Harvard University · 访问 ↗

Exercism

70+ 语言的练习题库，做完可以提交给真人导师点评——这是它和普通刷题站最大的差别，能拿到具体的改进建议。

授权：开源 MIT · 来源：github.com/exercism/exercism · 访问 ↗

中国大学 MOOC

国内高校的正式课程，计算机、数学、设计都有；免费可以看视频和讲义，想要证书或批改作业才需要付费。

授权：免费旁听（部分课程收费发证） · 来源：网易有道 & 高教社 · 访问 ↗

菜鸟教程

中文速查式教程，语法、示例、在线运行三件套齐全；不适合当系统教材，但查「某个语法怎么写」非常快。

授权：免费阅读（版权归站方） · 来源：runoob.com · 访问 ↗
