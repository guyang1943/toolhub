本地优先的开发者客户端

接口调试与数据库客户端：装在本地或自己部署，数据不出你的机器

合集导语

接口调试和数据库这两件事，过去十年基本被几个云端 SaaS 占着——接口集合存在别人的服务器上，登录才能用。这几年风向变了：一批开源客户端把数据拉回本地，接口定义变成能用 git 管理的纯文本，数据库连接直连你自己的库。这里收的六个都属于这一类：Bruno、Hoppscotch、Yaak 管接口，drawDB 画表结构，DbGate 与 DBeaver 连库。共同点是开源、可离线、不用注册账号；差别在于你更看重「团队协作走 git」「打开网页就能用」还是「一个客户端连遍所有库」。

怎么选

  • 接口集合要跟代码一起进 git、走评审：用 Bruno
  • 只是临时发个请求、不想装客户端：用 Hoppscotch 网页版
  • 先理清表结构和外键关系再动手建库：用 drawDB
  • 本机装着 MySQL / PostgreSQL / SQLite 好几个库：用 DbGate
  • 要一个客户端连遍所有库（含 Oracle、各类国产库）：用 DBeaver
  • 想要比 Bruno 更轻、同样能 git 同步的 API 客户端：用 Yaak

全部来源

Bruno

Postman 的替代品，但把接口集合存成本地文件夹里的纯文本（.bru 文件），能直接 git 管理、diff、走评审——接口定义终于和代码在同一个流程里。官方明说数据不出本机、无账号、无云同步。代价是团队共享靠 git 而不是云端协作，对不熟 git 的产品同学不算友好。

授权：MIT · 来源：github.com/usebruno/bruno · 访问 ↗

Hoppscotch

打开网页就能发请求，REST / GraphQL / WebSocket / SSE 都支持，还能装成 PWA 离线用。适合「临时验一个接口、不想为此装客户端」的场景。但网页版把请求历史存在哪里，官方文档没写死；碰敏感内网接口建议自己部署实例，别用公共站点。

授权：MIT · 来源：github.com/hoppscotch/hoppscotch · 访问 ↗

drawDB

浏览器里画 ER 图，建表、加字段、拉关系，画完直接导出 MySQL / PostgreSQL / SQLite 的建表语句，不用注册。官方 FAQ 写明数据存在浏览器本地（IndexedDB），换机器或清缓存就没了——重要模型记得导出 SQL 或 JSON 备份。

授权：AGPL-3.0 · 来源：github.com/drawdb-io/drawdb · 访问 ↗

DbGate

一个客户端连 MySQL、PostgreSQL、SQLite、SQL Server、MongoDB，带数据表格编辑和 SQL 编辑器，社区版开源。适合「本机装着好几个库、不想为每个库装一个 GUI」的人。注意 GPL-3.0 是社区版授权，想把它的代码集成进闭源产品需要另谈商业授权。

授权：GPL-3.0 · 来源：github.com/dbgate/dbgate · 访问 ↗

DBeaver

通用数据库客户端，靠 JDBC 连 MySQL、PostgreSQL、Oracle 乃至各类国产库，社区版 Apache-2.0 免费。启动慢、界面重，但 SQL 编辑、数据导出、ER 图都有，属于「装一个顶十个」的兜底选择。连接配置存本机；使用统计的默认值与上报范围未核实，连生产库前先翻偏好设置。

授权：Apache-2.0 · 来源：github.com/dbeaver/dbeaver · 访问 ↗

Yaak

Rust + Tauri 写的 API 客户端，安装包比 Electron 系小一圈。MIT、开源、不用注册。官方文档把「Git 同步工作区」列为协作方式，即接口集合按文件管、能进仓库走评审；落盘位置未逐条核实。生态比 Bruno 年轻，适合要轻量离线 REST / GraphQL 的人。

授权：MIT · 来源：github.com/mountain-loop/yaak · 访问 ↗
