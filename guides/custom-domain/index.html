🔗 给网站绑一个自己的域名

免费域名、改 DNS 解析、打开 HTTPS，告别 github.io 的长地址。

教程 / 给网站绑一个自己的域名
难度 入门约 30 分钟风险 低最后核对 2026-11-05
https://你的用户名.github.io/仓库名/ 能打开，但又长又难记。域名就是网站的门牌号：换成 www.yourname.bot.cd 这样的短地址，别人一眼记住、分享也方便。这篇用 DNSHE 的免费域名做例子，注册不要钱，解析自己说了算，30 分钟把新地址挂到你的 GitHub Pages 网站上，并打开免费的 HTTPS。

为什么值得折腾

  • 地址变短变好记，印在名片、发到群里都体面。
  • 换地方托管不用换地址：以后网站搬家，域名不变。
  • HTTPS 免费：GitHub 自动发证书，浏览器显示小锁头。

开工前要有的

  • 一个已经上线的 GitHub Pages 网站（第 1 篇的成果）。
  • 一个 DNSHE 账号：用邮箱注册，不用信用卡、不用实名。
  • 想好域名前缀，比如你的名字或项目名（小写字母、数字、连字符）。

步骤

  1. 在 DNSHE 注册一个免费域名

    打开 my.dnshe.com，点注册，用邮箱和密码建账号（不用绑信用卡，也不用实名认证）。登录后进「免费域名」或 Domain Hub，选一个后缀：.bot.cd 适合机器人和自动化项目，还有 .de5.net、.us.ci、.cc.cd 等可选（以后缀列表以控制台为准）。在输入框填你想要的前缀，比如 yourname，系统会实时告诉你能不能注册，确认后点「确认注册」。注册成功先别走，看一眼有效期：免费域名默认 1 年，到期前 180 天内可以免费续期，不续期会失效——在手机日历上记一个到期提醒。术语解释：域名分两段，前缀（yourname）是你起的名字，后缀（.bot.cd）是 DNSHE 提供的公共后缀；合起来 yourname.bot.cd 就是你的完整域名。

  2. 决定地址形式：www 开头最稳

    填 GitHub 之前先定好用哪种地址。GitHub 官方推荐用 www 子域名做主地址（比如 www.yourname.bot.cd），因为它最稳：GitHub 换服务器 IP 也不会影响你。根域名（不带 www 的 yourname.bot.cd）也可以用，但要配 A 记录。本篇两个都配：www 走 CNAME，根域名走 A 记录，配好后两个地址都能打开，GitHub 还会自动在两者之间跳转。术语解释：子域名是域名前面的那一段（www 就是最常见的子域名）；根域名（apex domain）是不带任何前缀的裸域名。

  3. 在 GitHub 填上自定义域名

    打开你的 GitHub 仓库，点 Settings → 左侧 Pages。找到 Custom domain（自定义域名）输入框，填 www.yourname.bot.cd，点 Save（保存）。保存后 GitHub 会在你的仓库里自动生成一个 CNAME 文件，里面就是你的域名——这个文件别删、别改，删了域名就掉了。填完先别急着勾 HTTPS，往下看第 5、6 步。

  4. 在 DNSHE 里加解析记录

    回到 DNSHE 的域名管理，找到你的域名，点 DNS 解析（或 DNS 记录）。先加一条 CNAME 记录：主机/名称填 www，记录值填 你的用户名.github.io（只填用户名，不要带仓库名）。再加四条 A 记录：主机/名称填 @（@ 就代表根域名本身），记录值依次填 185.199.108.153、185.199.109.153、185.199.110.153、185.199.111.153——这是 GitHub Pages 的四个官方 IP。TTL（生效时间）不用动，默认即可。保存后列表里应该有 1 条 CNAME 和 4 条 A 记录。如果域名之前有系统自带的“停放页”解析，把它删掉，否则会冲突。

  5. 等 DNS 生效（几分钟到几小时）

    DNS 不是改完立刻全世界生效的：它要一层层同步，通常几分钟到几小时，官方说最多 24 小时。验证办法：打开 dnschecker.org，输入你的域名选 A 记录查——看到 185.199.108.153 这些 IP 在全球陆续变绿，就是生效了。也可以直接在浏览器打开 http://www.yourname.bot.cd（注意先用 http 不是 https），能打开你的页面就说明通了。还没通就等一等，改解析后反复点保存没有用。

  6. 打开 Enforce HTTPS，看到小锁头

    DNS 检查通过后，回到仓库的 Settings → Pages，Enforce HTTPS（强制 HTTPS）复选框会从灰色变成可选，勾上它。GitHub 会免费发一张证书（Let's Encrypt，自动续期），一般几分钟到 1 小时完成；官方说最多可能要 24 小时才出现这个选项。再打开 https://www.yourname.bot.cd，地址栏出现小锁头，点锁头能看到证书信息，就成功了。从此别人输 http 也会自动跳到 https。做完后可以用 ToolHub 的二维码生成工具把新域名做成二维码，印在名片上。

翻车了怎么办

  • DNS 一直不生效：检查 CNAME 值是不是只写了 用户名.github.io（带仓库名就错了）；检查旧的停放解析删了没有；等满 24 小时再看。
  • Enforce HTTPS 一直是灰色：等证书，最多 24 小时；还不行就把 Custom domain 删掉重填一次，再等一轮。
  • 打开域名看到别人的网站：CNAME 值填错了，回去核对是不是你的用户名。
  • 根域名能打开，www 打不开（或反过来）：两边记录都要配齐，CNAME 和 A 记录缺一不可。

容易踩的坑

改解析时删了 MX 记录
MX 记录管邮箱收信。只动 A 记录和 CNAME，别碰 MX、TXT 这些不认识的记录，删了邮箱就收不到信了。
建了通配符 * 解析
别建 *.yourname.bot.cd 这样的通配符记录。GitHub 官方明确不建议：它会让别人有机会抢注你的子域名，带来域名劫持风险。
域名到期忘了续
免费域名默认 1 年，到期不续会被收回，别人能注册走。到期前 180 天内就能免费续期，设个日历提醒。
CNAME 文件被删了
GitHub 在仓库里生成的 CNAME 文件就是域名配置本身。清理仓库文件时别删它，删了域名就解绑了。
域名还没生效就反复改
DNS 同步要时间，改完就等。用 dnschecker.org 看全球进度，别一小时改三遍，越改越慢。

常见问题

域名真的免费吗？
DNSHE 的免费域名注册不要钱，不用绑信用卡，有效期默认 1 年，到期前 180 天内免费续期（续期次数不设上限）。它也提供“好友助力免费升级永久有效”的入口，以控制台为准。如果想要 .com 这样的顶级域名，就要去 Namecheap、Cloudflare Registrar 这些地方付费买，.com 大约每年 10 美元上下，以官网标价为准。（这是 DNSHE 后缀下的免费子域名；具体有效期以控制台显示为准，不同后缀可能不同。）
一定要用 www 吗？
不一定，但 GitHub 官方推荐 www 做主地址，因为它不受 GitHub 服务器换 IP 的影响，最稳定。根域名和 www 一起配，两个都能打开，GitHub 会自动跳转。
证书要钱吗？多久续一次？
不要钱。GitHub 用 Let's Encrypt 免费发，自动续期，你不用管。
以后网站不想放 GitHub 了，域名怎么办？
域名是你的，改解析就行：把 CNAME/A 记录指向新地方，地址不变，访客无感。这就是自己域名的好处。
