⚡ 手机自动化：快捷指令 / Tasker 入门

到公司自动连 Wi-Fi、到点提醒喝水、顺手备份照片，三个现成配方。

教程 / 手机自动化：快捷指令 / Tasker 入门
难度 中等约 40 分钟风险 低最后核对 2026-11-05
手机自动化就是"到条件、做动作"：到了公司就连 Wi-Fi，到了晚上 9 点就提醒你喝水。你不用写代码，只要选一个触发条件（时间、地点、连上某个 Wi-Fi），再选一串动作（开 Wi-Fi、静音、发通知），手机以后就自己执行。iPhone 用系统自带的"快捷指令"，免费；安卓用 Tasker，付费但功能最全。

为什么值得折腾

  • 每天省掉几十次重复操作。连 Wi-Fi、静音、调亮度这些小事，一天做几十遍，自动化之后一次都不用管。
  • 不用装一堆 App。一个自动化顶好几个提醒类 App，还不用给它们开一堆权限。
  • 配方可以照抄。本篇三个配方按步骤点就行，跑通一个，改条件和动作就能变出自己的。

开工前要有的

  • iPhone：系统自带的"快捷指令"App（iOS 13 及以上都有，免费）。安卓：Tasker（Google Play 一次性付费购买，美区现价约 $4.49，按地区定价，以商店页面为准；7 天免费试用版需从官网下载，无订阅）。
  • 知道公司和家的地址（配方一要用位置触发）。位置触发需要把定位权限设为"始终允许"，否则锁屏时触发不了。
  • 做之前先想好：触发条件是什么、触发后要手机做什么。先想后点，少走弯路。

步骤

  1. 先分清你用哪一边

    iPhone 只用"快捷指令"（免费自带）；安卓用 Tasker；三星手机自带"模式与日常程序"（旧称 Bixby Routines，设置里找）、部分小米手机（MIUI 14 / HyperOS 国行等版本）有隐藏的"自动任务"功能，但不是每台小米都有，找不到就直接用 Tasker，功能简单但免费，先用它们练手也行。本篇配方一、二是 iPhone，配方三是 Tasker。

  2. 配方一：到公司自动连 Wi-Fi、静音（iPhone）

    打开"快捷指令"→ 底部点"自动化"→ 右上角 + → 选"到达"→ 点"选取"搜公司地址，地图上拖动蓝色圆圈调触发范围（默认 100 米左右）→ 下一步 →"添加操作"→ 搜"设定 Wi-Fi"选"开"→ 再添加动作，搜"设定专注模式"，选"打开"，专注模式选"勿扰模式"→ 点下一步 → 关掉"运行前询问"（选"不询问"）→ 点"完成"。成功的标志：第二天到公司，手机自动连上公司 Wi-Fi、进入勿扰，不用你点任何东西。

  3. 为什么要关"运行前询问"

    默认开着的话，每次触发手机只会弹通知问你"要不要运行"，你还得手动点，自动化就白做了。苹果官方说明里，"到达""特定时间""无线局域网"这些触发都可以关掉询问、直接运行。注意：个别操作可能仍需单独授权或在锁屏下受限，以实际测试为准；如果某一步总弹确认，把它换成通知提醒、手动确认后再做。

  4. 配方二：每天 21:00 提醒喝水、备份照片（iPhone）

    自动化 → + → 选"特定时间"→ 设 21:00，重复选"每天"→ 下一步 → 添加操作 → 搜"显示通知"，文字写"该喝水了，顺手把今天的照片备份一下"→ 再加一个动作"打开 App"选"照片"→ 关掉"运行前询问"→ 完成。成功的标志：每天 21:00 手机准时弹出这条提醒。

  5. 配方三：晚上 23:00 自动进夜间模式（Tasker，安卓）

    打开 Tasker → 点 + 新建"配置文件"→ 起名"夜间模式"→ 选触发条件"时间"→ 设 23:00 到 7:00 → 点"新建任务"起名"夜间"→ 点 + 加动作：先加"勿扰模式"设为开，再加"显示亮度"设为 20 → 返回保存。Tasker 的逻辑就两层：配置文件就是"什么时候触发"，任务就是"触发后做什么"。

  6. 给夜间模式加一个"退出任务"

    长按刚才的配置文件 → 点"添加退出任务"→ 新建任务"白天"→ 动作：勿扰模式关、显示亮度恢复自动。没有退出任务的话，早上 7 点过了，手机还留在勿扰和暗屏状态。

  7. Tasker 的两处权限，别漏

    第一处：定位权限设为"始终允许"（如果配方里用了位置触发）；第二处：电池优化白名单——长按 Tasker 图标 → 应用信息 → 电池 → 选"无限制"（或"不优化"，不同手机叫法不同）；三星还需检查"电池 → 后台使用限制"，小米还需在"设置 → 应用 → 自启动"里打开 Tasker。找不到时直接在设置顶部的搜索框搜"电池优化"。不然系统会在后台杀掉它，时间到了也不执行。权限申请时系统会一步步弹窗，照着点"允许"就行。

  8. 测试与排错：先手动跑一次

    每个配方做完先手动点运行按钮试一次，确认动作都对。再等一次真实触发验证。没触发时按顺序查三处：定位权限是不是"始终"、"运行前询问"关了没有、电池优化有没有放行。三处都对还不行，就把触发范围调大一点（比如公司位置圆圈从 100 米调到 200 米）。

翻车了怎么办

  • 到公司没自动执行：按顺序查三处——定位权限是不是「始终允许」（不是「使用期间」）、「运行前询问」关了没有、触发范围够不够大（公司位置圆圈从 100 米调到 200 米）；三处都对还不行，把这个自动化删掉重建一次。
  • 每天 21:00 的提醒没弹：先确认「运行前询问」已关；再确认手机那段时间不是勿扰或专注模式把通知压住了；最后手动点一次运行按钮，确认动作本身没错。
  • Tasker 时间到了不执行：长按 Tasker 图标 → 应用信息 → 电池 → 选「无限制」（或「不优化」，不同手机叫法不同）；三星还需检查「电池 → 后台使用限制」，小米还需在「设置 → 应用 → 自启动」里打开 Tasker。找不到时直接在设置顶部的搜索框搜「电池优化」。系统在后台杀掉它是最常见的原因；再确认 Tasker 的权限都给了（定位「始终」、通知权限）。
  • 自动化运行时弹了询问还要手动点：个别操作可能仍需单独授权或在锁屏下受限，以实际测试为准，这是系统限制，不是设置错了；如果某一步总弹确认，把它换成通知提醒、手动确认后再做。

容易踩的坑

定位权限只给「使用期间」
位置触发的自动化在锁屏时也要靠定位判断，「使用期间」权限下锁屏后收不到位置，触发不了；必须设「始终允许」。
忘了关「运行前询问」
默认开着的话，每次触发只弹通知问「要不要运行」，还得手动点，自动化白做了；建好后第一时间关掉。个别操作可能仍需单独授权或在锁屏下受限，以实际测试为准。
Tasker 没进电池优化白名单
安卓系统会在后台杀掉 Tasker，时间到了也不执行；长按 Tasker 图标 → 应用信息 → 电池 → 选「无限制」（或「不优化」，不同手机叫法不同）；三星还需检查「电池 → 后台使用限制」，小米还需在「设置 → 应用 → 自启动」里打开 Tasker。找不到时直接在设置顶部的搜索框搜「电池优化」。
夜间模式没有退出任务
只做了 23:00 进夜间模式、没做 7:00 的退出任务，早上起来手机还留在勿扰和暗屏状态；配置文件和退出任务要成对做。

常见问题

快捷指令和 Tasker 哪个免费？
iPhone 的快捷指令是系统自带、免费；Tasker 是安卓上的一次性付费购买（美区现价约 $4.49，按地区定价，以商店页面为准），7 天免费试用版需从官网下载，无订阅。三星「模式与日常程序」（旧称 Bixby Routines）和部分小米手机的「自动任务」免费但功能简单，适合先练手。
自动化会不会半夜自己发短信、删照片？
个别操作可能仍需单独授权或在锁屏下受限，以实际测试为准；如果某一步总弹确认，把它换成通知提醒、手动确认后再做。日常配方（连 Wi-Fi、静音、调亮度、弹通知）可以关掉询问直接运行。
位置触发要一直开着定位吗？耗电吗？
要把定位权限设为「始终允许」，但不用一直开 GPS 高精度定位——系统用基站和 Wi-Fi 大致判断位置，耗电很小。触发范围调得太大（比如 500 米）会提前触发，100–200 米比较合适。
一个自动化能做几件事？
能串一串动作：到公司 → 连 Wi-Fi → 开勿扰 → 调亮度 → 发通知，一次触发全执行。动作越多越要先手动跑一次，确认每一步都对。
换了手机，自动化要重做吗？
iPhone 的快捷指令会通过 iCloud 同步到新手机，但自动化建议在新手机上打开检查一遍触发条件；Tasker 的配置可以导出备份文件，换机后导入恢复。
