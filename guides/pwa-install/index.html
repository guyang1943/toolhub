📱 把网站变成手机 App（PWA 篇）

加三样东西，网站就能安装到手机桌面、离线打开、像原生 App 一样全屏。

教程 / 把网站变成手机 App（PWA 篇）
难度 中等约 45 分钟风险 低最后核对 2026-11-06
PWA（Progressive Web App，渐进式网页应用）不是另外一种 App，而是在普通网站上加三样东西：一个描述文件、一个后台脚本、一条 HTTPS 连接。加完之后，浏览器会把你的网站当成 App 对待：手机桌面出现图标，点开是全屏、没有地址栏，断网也能打开看过的内容。本站 ToolHub 自己就是 PWA，你现在用的就是活例子。

为什么值得折腾

  • 不用上架应用商店。没有审核、没有 30% 抽成、不用等排期，改完代码用户下次打开就是新版。
  • 一次做好，安卓和苹果都能装。同一套文件，两边都能安装到桌面。
  • 离线也能用。看过的内容缓存在手机里，没网、信号差的时候也能打开。

开工前要有的

  • 一个已经上线的网站（本篇以 GitHub Pages 为例，它自带 HTTPS）。
  • 两张正方形图标：192×192 和 512×512 像素的 PNG 文件。没有的话先用站内的图片缩放和图片格式转换工具做两张。
  • 一台能装网站的安卓手机或 iPhone，以及一台电脑（改文件用）。
  • 会打开浏览器的开发者工具（按 F12 就行，本篇只用它来检查，不写代码调试）。

步骤

  1. 先确认网站是 HTTPS

    地址栏看到小锁头就是 HTTPS。GitHub Pages 的站默认就是 HTTPS：在仓库 Settings → Pages 里确认 Enforce HTTPS 是打开的。Service Worker（后台脚本）和安装都只在 HTTPS 下工作，http:// 的站装不了——本地测试时 http://localhost 是例外，不用管。

  2. 准备两张图标

    192×192 和 512×512 各一张，PNG 格式，内容尽量简单（纯色底加字母或图形），因为小图标上细节看不清。把它们放进网站根目录，起名 icon-192.png 和 icon-512.png。

  3. 写 manifest：给网站一张身份证

    新建一个文件 site.webmanifest（就是一个 JSON 文本文件），写这几项：name（完整名字）、short_name（桌面上显示的短名字，8 个字以内最好）、icons（上面两张图的路径和尺寸）、start_url（打开 App 时先去哪个页面，写 "/"）、display（写 "standalone"，意思是全屏打开、不显示浏览器地址栏）、background_color 和 theme_color（启动时的底色和顶栏颜色）。manifest 是什么？浏览器靠它知道"这个网站叫什么、用什么图标、打开后长什么样"。

  4. 在每个页面里引用它

    在每个 HTML 页面的 <head> 里加一行：

    <link rel="manifest" href="/site.webmanifest">

    漏了这一行的页面，浏览器不知道网站有 manifest，装不了。加完后刷新页面。

  5. 写 Service Worker：离线能打开的关键

    新建一个文件 sw.js。Service Worker 是浏览器在后台运行的一段脚本：它坐在网页和网络之间，第一次联网时把首页和关键文件存进手机缓存，之后没网就从缓存里拿。最简单的写法是"先缓存首页、样式和脚本，请求时先看缓存、没有再联网"。注意：Service Worker 文件必须放在网站根目录，作用范围才是整个站。

  6. 在页面里注册它

    在首页加一小段脚本：navigator.serviceWorker.register('/sw.js')。刷新后按 F12 打开开发者工具 → Application（应用）→ Service Workers，看到状态是 activated（已激活）就说明注册成功了。

  7. 安卓手机：点一下就能装

    电脑上用 Chrome 打开你的网站，等几秒，地址栏右边会出现一个安装图标（电脑形状带向下箭头）；点它，再点"安装"。安卓手机上用 Chrome 打开网站，等几秒，点右上角菜单 →"安装应用"或"添加到主屏幕"。成功的标志：桌面多了一个图标，点开是全屏、没有地址栏。Chrome 有个小细节：从 Chrome 108 起，manifest 加 HTTPS 就能从菜单安装；但要触发自动安装提示（beforeinstallprompt），仍需要带 fetch 处理的 Service Worker——所以第 5 步别省。

  8. iPhone：手动从分享菜单加

    iPhone 没有安装提示，必须手动来：用 Safari 打开网站 → 点底部的分享按钮（方框带向上箭头）→ 往下划点"添加到主屏幕" → 点右上角"添加"。成功的标志和安卓一样：桌面出现图标，全屏打开。从 iOS 16.4 起，添加到主屏幕的网页 App 还能收推送通知，但前提是网站自己实现了 Web Push（Service Worker + 推送订阅），且用户在 App 内点过允许；只装不订阅是收不到的。Safari 里做最稳妥；iOS 16.4 起，Chrome、Edge 等第三方浏览器的分享菜单里也有'添加到主屏幕'，效果一样。

  9. 验证离线：开飞行模式再打开

    手机开飞行模式，点桌面图标打开网站：首页和已经看过的页面应该能正常显示。没缓存过的页面会显示浏览器的默认离线提示，这是正常的——离线范围就是 Service Worker 缓存过的内容，不是整个互联网。本站实测过（2026-11-06，线上 toolhub.bot.cd）：Service Worker 处于 activated 并已接管页面，断网后首页与工具页都照常打开。

翻车了怎么办

  • 安装图标不出现：按 Chrome 官方的可安装清单逐项核对——manifest 里有 name 或 short_name、192×192 和 512×512 两张图标、start_url、display 是 standalone、fullscreen 或 minimal-ui 之一、prefer_related_applications 不是 true；还要确认网站是 HTTPS。再打开 F12 → Application → Service Workers，确认状态是 activated。三项都对还不行，用无痕窗口重开一次，排除缓存干扰。
  • Service Worker 注册失败：先确认 sw.js 在网站根目录（不在子文件夹里）；再确认是 HTTPS（本地测试时 http://localhost 是例外）；打开 F12 → Console 看报错信息，按报错改；改完后在 Application → Service Workers 点「更新」，再硬刷新页面。
  • 离线打不开首页：先确认 Service Worker 已激活，并且联网状态下打开过一次首页（没打开过就没进缓存）；没缓存过的页面离线本来就打不开，这是正常的；想让更多页面离线可用，把它们也加进 Service Worker 的缓存列表。
  • iPhone 上找不到「添加到主屏幕」：Safari 里做最稳妥；iOS 16.4 起，Chrome、Edge 等第三方浏览器的分享菜单里也有「添加到主屏幕」，效果一样；点 Safari 底部中间的分享按钮（方框带向上箭头），往下划找「添加到主屏幕」；如果分享菜单里没有，先确认打开的是 Safari 而不是别的浏览器。

容易踩的坑

manifest 里图标路径写错
icons 里的 src 是相对网站根目录的路径，图标文件放根目录就写 "/icon-192.png"；路径错一个字，浏览器就认不到图标，安装直接失败。改完后在 F12 → Application → Manifest 里看图标能不能正常显示。
Service Worker 放进子文件夹
sw.js 必须放在网站根目录，它的作用范围就是它所在的文件夹及以下；放进 /js/ 里，它就只能管 /js/ 下的页面，首页缓存不了。
display 写了 browser
display 必须是 standalone（或 fullscreen、minimal-ui），写 browser 等于告诉浏览器「还按网页打开」，装完还是带地址栏的普通网页，等于白装。
只在电脑上测，不在手机上测
电脑 Chrome 能装不代表手机能装——图标在手机桌面上的效果、iPhone 只能 Safari 手动加、离线表现，都要在真机上验一遍。

常见问题

PWA 和原生 App 有什么区别？
PWA 不用上架应用商店、不用审核、没有 30% 抽成，改完代码用户下次打开就是新版；代价是不能用全部系统能力（比如 iOS 上推送、蓝牙等受限），适合内容、工具类应用，不适合重度游戏或要调用特殊硬件的场景。
用户手机没网时，PWA 还能打开吗？
能打开缓存过的内容——首页和之前看过的页面。没缓存过的页面会显示浏览器的默认离线提示。离线范围就是 Service Worker 缓存过的内容，不是整个互联网。
一定要 512×512 的图标吗？
要。Chrome 的可安装清单明确要求 192×192 和 512×512 各一张，缺一张就不算可安装。图标内容尽量简单，小尺寸下细节看不清。
iPhone 上为什么没有安装提示？
iPhone 不弹安装提示，必须手动操作：Safari 打开网站 → 底部分享按钮 →「添加到主屏幕」。从 iOS 16.4 起，添加到主屏幕的网页 App 还能收推送通知，但前提是网站自己实现了 Web Push（Service Worker + 推送订阅），且用户在 App 内点过允许；只装不订阅是收不到的。
改了网站内容，手机上的 PWA 会更新吗？
会。下次联网打开时，浏览器会检查 Service Worker 有没有新版本，有就后台更新，下次打开生效。改了 manifest（比如换图标）后，已安装的图标可能要卸载重装才换。
