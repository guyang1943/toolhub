🖥️ 在自己电脑上跑一个离线 AI 对话（Ollama 篇）

免费开源模型本地跑，聊天记录不出设备；旧电脑也能跑小模型。

教程 / 在自己电脑上跑一个离线 AI 对话（Ollama 篇）
难度 中等约 60 分钟风险 中最后核对 2026-11-05
Ollama 是一个免费工具，能让你在自己的电脑上跑开源大模型：下载、聊天都在本机完成，聊天记录不出设备，不用订阅、不用联网也能用。本篇先讲清楚你的电脑能不能跑，再一步步装好、拉模型、开始对话。旧电脑也能跑小模型，只是回答慢一点。

为什么值得折腾

  • 隐私：聊天记录只存在你的电脑上，不上传、不留痕，问私事也安心。
  • 免费：模型本身不要钱，不用订阅、不按条数收费，下载一次一直用。
  • 断网也能用：模型下载完之后，飞机上、没网的地方都能聊。

开工前要有的

  • 一台电脑：Windows 10（22H2 或更新）/ Windows 11，或 macOS 14（Sonoma）或更新，或 Linux。
  • 内存对照表（Ollama 官方说明）：8GB 内存跑 7B 模型是底线（能跑但慢）、跑 3B 小模型最稳；16GB 跑 13B；32GB 跑 33B。旧电脑请先看第 1 步。
  • 至少 10GB 空闲磁盘空间（一个小模型约 2GB，多备几个模型要更多）。
  • 下载模型时需要联网，下载完之后可以断网使用。

步骤

  1. 先看你的电脑能不能跑：查内存

    先看自己电脑的内存，再决定跑多大的模型。Windows：按 Ctrl+Shift+Esc 打开任务管理器，点“性能”，点“内存”，看右上角的数字。Mac：点左上角苹果菜单 →“关于本机”，看“内存”。对照表（Ollama 官方说明）：8GB 内存跑 7B 模型是底线（能跑但慢）、跑 3B 小模型最稳；16GB 跑 13B；32GB 跑 33B。低于 8GB 就别试了，先用免费在线聊天。成功标志：你知道了自己的内存数字，也知道了该拉哪个档位的模型。

  2. 去官网下载安装 Ollama

    打开浏览器，去 ollama.com/download（Ollama 官网下载页）。Windows：下载 OllamaSetup.exe，双击安装，一路点“下一步”，装完右下角托盘会出现一只小羊驼图标。Mac：下载 Ollama.dmg，打开后把 Ollama 拖进“应用程序”，再打开一次。Linux：在终端里粘贴官方安装命令 curl -fsSL https://ollama.com/install.sh | sh，等它跑完。成功标志：电脑上出现 Ollama 的图标或服务（Windows 托盘有图标，Mac 菜单栏有图标）。

  3. 确认装好了：输一行命令看版本号

    确认 Ollama 装好了。Windows：按 Win+R，输入 cmd 回车，打开黑色命令行窗口；Mac：打开“终端”（在“应用程序 → 实用工具”里）。输入 ollama --version 再回车。成功标志：窗口里出现一串版本号，比如 ollama version is 0.x.x。如果提示“找不到命令”，先重启电脑再试一次。

  4. 拉第一个模型：从最小的 3B 开始

    拉第一个模型。初学者建议从最小的开始：在命令行里输入 ollama pull llama3.2:3b 再回车。这个模型约 2GB，下载要几分钟到十几分钟，看网速。成功标志：最后一行出现 success，或者进度条走完回到可以输入的状态。下载一半不要关窗口。

  5. 开始对话：第一句问候

    在命令行里输入 ollama run llama3.2:3b 再回车，第一次会稍等一会儿加载模型，然后出现 >>> 提示符，就可以打字聊天了。试着问一句“用三句话介绍一下你自己”。成功标志：模型用中文回答了你的问题。想退出时输入 /bye 再回车。聊天记录只存在你的电脑上，不会上传。

  6. 内存够的话，换个更大的模型试试

    如果你的电脑内存有 16GB，可以试试更大的模型，回答质量会好一些。输入 ollama pull qwen2.5:7b（约 4.7GB），下载完再输入 ollama run qwen2.5:7b 开始聊。成功标志：新模型能正常对话。内存只有 8GB 就别试这一步，3B 模型够用了。

  7. 看看装了哪些模型，不想要的删掉

    输入 ollama list 可以看到你已经下载了哪些模型和它们的大小。某个模型不想留了，输入 ollama rm 模型名 删掉它（比如 ollama rm llama3.2:3b），能腾出磁盘空间。成功标志：ollama list 里不再出现被删的模型。

  8. 不想敲命令：装 GPT4All 图形界面

    如果你不想碰命令行，还有图形界面的选择：去 gpt4all.io（GPT4All 官网）下载安装，打开后在软件里点一点选模型、下载、聊天，全程不用敲命令。GPT4All 是免费开源软件，模型同样在本地跑。成功标志：打开 GPT4All，选好模型，能打字聊天。

翻车了怎么办

  • 模型下不动：检查磁盘空间（3B 模型约 2GB），空间够就换个网络环境再试一次；还是不行就换更小的模型。
  • 对话太慢：先关掉其他占内存的程序（浏览器、视频软件）；还是慢就换 3B 小模型，或者接受它慢一点——本地小模型本来就比云端慢。
  • 电脑实在跑不动：直接用免费在线聊天（DeepSeek 网页版完全免费，或 ChatGPT 免费版），本地模型以后再试。

容易踩的坑

不看内存，硬拉大模型
模型是按大小分的，7B 模型约 5GB，13B 约 7–9GB（看具体模型），70B 要 64GB 内存。只看名字好听就拉 70B，电脑会直接卡住。先看第 1 步的对照表，按内存选。
拉到 :cloud 模型会花钱
模型库里名字带 :cloud 后缀的模型（比如 qwen3.5:cloud）是跑在 Ollama 服务器上的，按 token 计费，不是本地免费模型。用 :cloud 模型要先登录 Ollama 账号，聊天内容会发到 Ollama 服务器。拉模型时认准没有 :cloud 的名字。
以为下载是秒完成的
模型文件几个 GB，第一次下载要几分钟到十几分钟，看网速。下载一半关掉，下次要重新下。
断网了还想下载模型
下载模型要联网；下载完之后聊天可以断网。别在没网的时候下载。

常见问题

我的旧电脑只有 8GB 内存，能跑吗？
8GB 内存可以跑 3B 小模型（比如 llama3.2:3b，约 2GB），回答会慢一点，但能用。16GB 内存跑 7B、8B 模型比较顺。低于 8GB 就别试了，先用免费在线聊天。
模型存在电脑的哪里？
Windows 在 C:\Users\你的用户名\.ollama\models，Mac 在 ~/.ollama/models，Linux 在 /usr/share/ollama/.ollama/models。删模型用 ollama rm 模型名（删了要重新下载才能用，没有确认提示）。
本地模型能联网查今天的新闻吗？
不能。本地模型只知道它训练时学到的东西，不知道今天的新闻、天气和股价。需要查实时信息时，用联网的免费聊天工具。
本地模型和 ChatGPT 比，哪个更强？
写东西、改文章、总结文档，本地 7B、8B 模型够用；复杂推理、写代码、长文创作还是云端大模型更强。本地胜在隐私和免费，不胜在聪明。
断网了还能用吗？
第一次下载模型必须联网（几个 GB）。下载完之后，聊天可以完全断网进行。
