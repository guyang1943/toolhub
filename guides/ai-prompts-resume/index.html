✍️ 零基础用 AI 写简历、周报和方案

提示词模板直接抄，改三处就能用；附 Token 成本估算。

教程 / 零基础用 AI 写简历、周报和方案
难度 入门约 30 分钟风险 低最后核对 2026-11-05
“提示词”就是跟 AI 说话的写法：写得越具体，AI 给的东西越能用。本篇不讲理论，直接给三个能抄的提示词模板——改简历、写周报、写方案，改三处就能用。做完你会发现，写东西的难处不在“想不出来”，而在“没说清楚要什么”。

为什么值得折腾

  • 模板改三处就能用：不用学理论，抄过去、填上方括号里的三处，马上能出东西。
  • 免费版就能做：ChatGPT 免费版、DeepSeek 都不要钱，日常写东西够用。
  • 先估成本再动手：用 ToolHub 的 token-counter 工具看一眼 Token 数，花钱之前心里有数。

开工前要有的

  • 一个免费 AI 聊天账号：ChatGPT 免费版（日常文字聊天不限条数）或 DeepSeek（网页和手机聊天完全免费，聊天版没有付费套餐，开发者用的 API 是另外按量计费的），注册只要邮箱或手机号。
  • 要改的原始材料：旧简历、这周的工作记录、方案的背景资料。先准备好，写提示词时直接贴进去。
  • 记住一条红线：身份证号、薪资、合同、客户资料不要贴（见文末'常见坑'与 FAQ）。

步骤

  1. 先选一个免费聊天工具

    先选一个免费聊天工具，不用两个都装。ChatGPT 免费版：打开 chatgpt.com，注册账号就能用，日常文字聊天不限条数。DeepSeek：搜“DeepSeek”打开官网，网页和手机聊天完全免费，聊天版没有付费套餐（开发者用的 API 是另外按量计费的），不会中途推销。成功标志：能正常打字聊天，AI 回了你第一句话。

  2. 模板一：改简历——给背景、给成绩、给要求

    把下面这个模板抄过去，改三个地方（方括号里标了）：

    “请帮我改一份简历。我的背景：[我是做电商运营的，3 年经验]；目标岗位：[高级运营经理]；我的三条成绩：[1. 负责店铺月销从 50 万做到 200 万；2. 搭建了客服话术库，回复时间缩短一半；3. 带过 3 人小组]。要求：每条成绩用“动词 + 数字 + 结果”写，一页纸能放下，语气专业、不浮夸。”

    成功标志：AI 给出的简历每条都有数字和结果，而不是“负责日常运营”这种空话。

  3. 模板二：写周报——分段要，行数要少

    把下面这个模板抄过去，改三个地方：

    “请帮我写一份周报。我的岗位：[产品经理]；本周做的事：[1. 上线了新版搜索页；2. 和设计对了三版首页图；3. 处理了 5 个用户反馈的闪退问题]；下周计划：[灰度新版首页，覆盖 10% 用户]。要求：分“本周完成 / 下周计划 / 需要支持”三段，每段不超过 5 行，语气简洁。”

    成功标志：周报结构清楚，老板一眼能看到“做了什么”和“要什么支持”。

  4. 模板三：写方案——先要大纲，再展开

    把下面这个模板抄过去，改三个地方：

    “请帮我写一份方案。背景：[公司想在下季度做一场线上新品发布会，预算 5 万元]；目标：[吸引 2000 人报名，转化 100 单]；限制：[团队只有 3 个人，没有线下场地]。要求：先给大纲（目标、渠道、时间表、预算分配），再展开第一部分，语气务实，不要空话。”

    成功标志：AI 先给大纲再展开，而不是一上来就写一大段散文。大纲不对就让它先改大纲，别急着写全文。

  5. 提问之后要追问，别一次就接受

    AI 第一次给的东西很少能直接用，要追问。常用的三句追问：“改短一半”“换个更正式的语气”“再给两个版本，我挑一个”。成功标志：改过两轮之后，文字读起来像你自己写的，而不是 AI 的腔调。

  6. 核对事实再发：数字、时间、公司名逐条过

    发出去之前逐条核对：数字对不对（销售额、人数、时间），公司名、职位名有没有写错，有没有 AI 编出来的经历。成功标志：每一处数字你都能说出出处。

  7. 估算成本：先用 token-counter 看 Token 数

    如果你用的是按量计费的 API（不是免费聊天版），先估成本再动手：把提示词粘进 ToolHub 的“Token 估算”工具，看大概多少 Token，再对照你用模型的官网定价算钱。免费聊天版不用算这步。成功标志：动手之前就知道这一问大概花多少钱。

翻车了怎么办

  • AI 写得不好：把提示词里的背景写得更具体（加上数字和例子），或者把大任务拆成三段分别问，再拼起来。
  • 免费版额度用完了：ChatGPT 免费版的上传、图片生成功能有限额，用完等明天重置；或者换 DeepSeek 继续写，它的聊天版没有付费套餐。
  • 想要更好的效果：把 AI 给的初稿当底稿，自己改一遍关键句子——AI 负责搭架子，你负责把关。

容易踩的坑

把敏感信息贴给 AI
身份证号、薪资、合同、客户资料、公司内部文件都不要贴进免费聊天工具。免费版的聊天记录可能被用来改进模型，贴之前先问自己一句：这段话出现在网上，我介意吗？
照单全收，不核对事实
AI 会一本正经地编数字和经历：没做过的事它也敢写。简历、周报、方案发出去之前，逐条核对数字、时间、公司名和职位名。
提示词写得太空
“帮我写个简历”太空了，AI 只能给你通用套话。好提示词要给三样东西：背景（你是谁、应聘什么）、材料（你的三条成绩）、要求（多长、什么语气）。
一次问到底，不追问
一个大问题一次问到底，效果最差。先让 AI 出框架，再一段一段追问、改细节，最后让它给三个版本挑一个。

常见问题

免费版够用吗？
日常写东西够用。ChatGPT 免费版的日常文字聊天不限条数，但上传文件、图片生成、语音这些是有限额的。DeepSeek 的网页和手机聊天完全免费，聊天版也没有付费套餐（开发者用的 API 是另外按量计费的）。
哪个免费工具最好？
ChatGPT 免费版最通用，什么都能写一点；DeepSeek 完全免费、没有推销，写中文、算数都不错。两个都免费，先用一个顺手的就行。
Token 是什么？和钱有什么关系？
Token 是 AI 计费和算长度的单位，可以理解成“字块”：一段话里中文、英文、符号占用的 Token 数不一样。先用 ToolHub 的 token-counter 工具估个大概数，再对照你用模型的官网定价算钱。免费聊天版不用算这步。
公司资料能贴给 AI 吗？
不要贴。身份证号、薪资、合同、客户资料、公司内部文件都不要贴进免费聊天工具——免费版的聊天记录可能被用来改进模型。只贴你愿意公开的那部分。不想被用来训练，可以在设置 → 数据控制里关掉'Improve the model for everyone'。
AI 会不会编造我的经历？
能，但要核对。AI 会一本正经地编数字和经历，写完逐条核对：数字、时间、公司名、职位名，错一处就改一处。
