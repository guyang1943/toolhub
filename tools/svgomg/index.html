SVGOMG · 官方在线版

SVG 优化压缩 GUI（SVGO 的可视化界面）

它解决什么问题

SVGOMG 是 SVGO 的图形界面：把设计师导出的 SVG 拖进去，实时看到优化前后的体积对比和预览。Figma/Sketch 导出的 SVG 常带大量无用属性（metadata、注释、默认值、多余分组），优化后体积通常能降 40%–70%，而且渲染结果完全一样。

三个典型使用场景

  1. 把设计师给的 logo SVG 从 80KB 压到 12KB 再放进项目
  2. 批量清理图标库里的冗余属性，减小打包体积
  3. 对比不同优化强度下的视觉差异，找到安全阈值

和 ToolHub 本地工具怎么配合

图片格式转换：优化后的 SVG 要给不支持矢量的地方用时，站内转 PNG 一步到位（本地工具，文件不上传）

图片转 Base64：小 SVG 内联进 CSS 时转 Data URI，省掉一次请求（本地工具，文件不上传）

同类可替代方案

  • Squoosh —— Google 出品的图片压缩，对比预览效果极佳
  • Picsum Photos —— 占位图服务，开发测试用假图一键生成
  • Tesseract.js OCR —— 浏览器本地图片文字识别（OCR）官方演示

使用时要注意什么

默认会合并路径和精度，某些含滤镜、动画、mask 的 SVG 优化后可能异常，必须逐张预览确认；不处理嵌入的位图。

常见问题

SVGOMG 是免费的吗？

SVGOMG 是开源项目，采用 MIT 许可证，官方在线版可以免费使用，不需要为基本功能付费。ToolHub 只做收录与说明，不代管你的数据，也不提供账号或存储服务。

SVGOMG 适合什么场景？

最常见的是这几种：把设计师给的 logo SVG 从 80KB 压到 12KB 再放进项目；批量清理图标库里的冗余属性，减小打包体积；对比不同优化强度下的视觉差异，找到安全阈值。判断标准很简单——如果你现在正为了这件事装一个几百 MB 的桌面软件，先用它试一次。

它和 ToolHub 的本地工具有什么区别？

ToolHub 的本地工具把代码放在你的浏览器里执行（WebAssembly 或原生 JS），文件不经过服务器；SVGOMG 由项目作者维护，数据在其服务器或你的浏览器中处理，具体取决于项目实现，使用前建议先看对方的数据政策。需要「绝对不上传」时可以改用站内同类工具。

用 SVGOMG 有什么限制？

默认会合并路径和精度，某些含滤镜、动画、mask 的 SVG 优化后可能异常，必须逐张预览确认；不处理嵌入的位图。
