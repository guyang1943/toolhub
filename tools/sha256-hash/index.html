哈希计算

SHA-256/384/512 哈希，基于 WebCrypto 安全实现

关于哈希计算

哈希函数把任意长度的输入映射成固定长度的摘要：同样的输入永远得到同样的输出，但无法从输出反推出输入，且改动一个字符结果就会完全不同。这种特性让它成为校验文件完整性、生成内容指纹的标准手段。SHA-256 输出 256 位（64 个十六进制字符），目前没有已知的实用碰撞攻击。

使用步骤

  1. 拖入文件或粘贴文本，选择算法（SHA-256 / 384 / 512）
  2. 等待计算完成，大文件按分片读入不会卡死页面
  3. 复制摘要值，与发布方官网公布的数值逐字符比对
  4. 文本模式可直接改内容，观察摘要如何随之变化

常见错误

比对时忽略大小写以外的问题

摘要值是十六进制文本，复制时容易带上空格或换行。逐字符完整比对，不要只看前几位。

用快速哈希（MD5）做安全校验

MD5 早已不抗碰撞，只能当校验和用；签名、证书、密码场景请用 SHA-256 及以上或专用算法。

把哈希当密码存储

SHA-256 计算太快，裸存密码等于给彩虹表留门。密码要用 bcrypt、scrypt、Argon2 这类慢哈希加盐存储。

常见问题

怎么验证下载的文件没被篡改？

在发布方官网找到官方摘要值，用本工具计算你手上文件的摘要，两者完全一致才说明未被修改。

SHA-1 还能用吗？

不能用于安全场景。SHA-1 已被证实可构造碰撞，仅在兼容老旧系统时保留，新项目请用 SHA-256 及以上。
