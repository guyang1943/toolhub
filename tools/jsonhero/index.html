JSON Hero · 官方在线版

高颜值 JSON 浏览器，结构一目了然

它解决什么问题

JSON Hero 解决的是「JSON 一多就看晕」的问题：它把一份 JSON 变成带缩略图、标题、颜色标记的可浏览对象，数组会折叠成卡片，字段会按类型上色。排查第三方 API 返回的复杂结构时，比在 500 行的格式化文本里滚来滚去快得多。它的核心机制是自动识别「像标题的字段」（name、title、id）来给每条记录生成摘要。

数据边界

怎么用上：🌐 在线直达（网页版，官网 jsonhero.io）

数据边界：会上传 —— 粘贴的 JSON 会存到对方服务器并生成可分享链接

三个典型使用场景

  1. 排查一个 2000 行的 API 响应，快速定位到出问题的嵌套对象
  2. 把 JSON 分享给同事看，用链接 + 高亮字段让对方直接看某一段
  3. 探索一份不熟悉的 JSON 数据集，先摸清字段结构和类型分布

和 ToolHub 本地工具怎么配合

JSON 格式化：结构简单（几百行以内）的 JSON 用站内格式化就够了，还能直接复制紧凑版（本地工具，文件不上传）

CSV ↔ JSON：JSON 里的数组要转成表格看时，站内 CSV 互转支持扁平化一行一条记录（本地工具，文件不上传）

同类可替代方案

  • CyberChef —— GCHQ 出品的数据解码/加密/转换瑞士军刀
  • Transform —— JSON/YAML/TOML/TS 等几十种格式互转
  • quicktype —— JSON 一键生成 TypeScript/Java/Go 等类型定义

使用时要注意什么

一次性加载整份 JSON 到内存，几十 MB 的文件会卡死；需要把数据粘贴到网页或通过 URL 加载，敏感数据别用它。

常见问题

JSON Hero 是免费的吗？

JSON Hero 是开源项目，采用 MIT 许可证，官方在线版可以免费使用，不需要为基本功能付费。ToolHub 只做收录与说明，不代管你的数据，也不提供账号或存储服务。

JSON Hero 适合什么场景？

最常见的是这几种：排查一个 2000 行的 API 响应，快速定位到出问题的嵌套对象；把 JSON 分享给同事看，用链接 + 高亮字段让对方直接看某一段；探索一份不熟悉的 JSON 数据集，先摸清字段结构和类型分布。判断标准很简单——如果你现在正为了这件事装一个几百 MB 的桌面软件，先用它试一次。

它和 ToolHub 的本地工具有什么区别？

ToolHub 的本地工具把代码放在你的浏览器里执行（WebAssembly 或原生 JS），文件不经过服务器；JSON Hero 由项目作者维护，数据在其服务器或你的浏览器中处理，具体取决于项目实现，使用前建议先看对方的数据政策。需要「绝对不上传」时可以改用站内同类工具。

用 JSON Hero 有什么限制？

一次性加载整份 JSON 到内存，几十 MB 的文件会卡死；需要把数据粘贴到网页或通过 URL 加载，敏感数据别用它。
