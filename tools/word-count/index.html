字数统计

中英文字数、字符、段落与阅读时长统计

关于字数统计

不同平台对字数的统计口径不一样：有的按字符数（含空格），有的只算汉字，有的把英文按单词计。投稿、公众号、论文摘要的字数限制如果按错口径核对，很容易在最后一步被打回。分开统计中英文与标点，才能对上平台规则。

使用步骤

  1. 粘贴或输入正文内容
  2. 查看分开统计的汉字数、英文单词数、字符数（含/不含空格）
  3. 按目标平台的口径取对应数字核对限制
  4. 参考阅读时长估算安排讲稿或视频节奏

常见错误

口径对不上平台

有的平台把标点计入字数，有的不计。提交前看清对方规则，取对应的统计项，别只看一个总数。

粘贴时带上格式残留

从 Word 或网页复制会带入零宽字符和全角空格，统计数虚高。先过一遍纯文本再计数。

英文按字符数估算

英文文章用“字符数”对字数限制没有意义，平台基本按单词计。双语内容要分开看两个口径。

常见问题

中文字数怎么算？

按汉字字符个数统计，不含标点与空格。这是公众号、多数内容平台采用的口径。

阅读时长准吗？

只是估算，按中文 400 字/分钟、英文 200 词/分钟计算，实际受内容难度与讲者语速影响。
