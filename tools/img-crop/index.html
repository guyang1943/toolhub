图片裁剪

拖出选区或填空坐标裁剪图片，支持等比锁定与圆角

关于图片裁剪

图片裁剪是把一张图里真正要用的那块单独切出来，而不是把它缩放到某个尺寸。手机截图、网页长图、相机原片里往往只有局部有用：一段对话、一个二维码、一张产品的正面。裁剪时像素是原样搬过去的，不经过缩放算法，所以画面不会因为裁剪本身变糊；但如果导出 JPEG，会重新编码一次，体积和画质的变化就来自这一步。

使用步骤

  1. 选一张图片，预览会出现在表单下方，并自动把宽高填成整图的像素
  2. 在预览图上按住拖出要保留的矩形；选了 1:1、16:9 等比例时，选框会跟着比例走
  3. 需要精确到像素时，直接改左上角 X/Y 与宽高四个数字，留空或填 0 表示一直到边缘
  4. 要做圆形头像就把圆角填成短边的一半（200×200 填 100），导出格式选 PNG 才能保留透明
  5. 点「裁剪」后在结果区下载，同时能看到原图尺寸 → 裁剪后尺寸与体积变化

常见错误

裁剪后反而变大

JPEG 重编码的质量固定在 0.92，而原图可能只用了 0.5～0.6 的压缩。裁掉一半画面，重编码后的字节数仍可能超过原文件。判断「裁剪有没有瘦身」要看尺寸和用途，不要只看体积。

圆角半径超过短边一半

200×200 的图填 200px 圆角，程序只能按 100px 处理，否则四个弧拼不出一个完整形状。结果区会提示实际使用的半径，看到数值被改小不是没生效。

把裁剪当压缩用

裁剪只改变画面范围，不做降采样。文章配图想要 800px 宽，应该先用「图片缩放」把边长降到 800，再决定裁不裁；反过来先裁再缩，会多损失一次画质。

常见问题

裁剪后文件反而比原图大，是不是工具出错了？

不是。JPEG 是有损格式，导出时会按质量 0.92 重编码一次；如果原图是从聊天软件转存来的、本身只用了很低的压缩质量，那么裁出一小块也可能比整张原图更大。想要更小的体积可以选 WebP，或者直接用「图片压缩」而不是裁剪。

圆角裁剪后导出 JPEG，四个角变成了白色方块？

JPEG 没有透明通道，圆角以外的区域只能填色，工具默认填白。需要透明背景请把导出格式改成 PNG 或 WebP，圆角外就是透明的。

裁剪框填得比图片还大怎么办？

宽高越过右/下边缘时会自动收缩到图内，并在结果上方提示收缩后的实际尺寸——不会产出一张带空白边的图。如果起点本身就落在图片外面，会直接报错并告诉你图片的真实尺寸。

固定比例和自由裁剪怎么选？

要发到固定版位（头像、封面、商品主图）用固定比例，能保证不被平台二次裁切；只是想去掉多余部分用自由裁剪。平台规格经常变，拿不准时按最严格的方形裁，其他地方用留白补。

原图会被覆盖吗？

不会。裁剪结果作为新文件下载，原图始终在你磁盘上不动。这一点很重要——浏览器拿不到写回原文件的权限，任何声称能「原地修改」的网页工具都只是在让你重新下载。
