磁盘整数分区规划

按整数 GB 规划磁盘分区，校验容量是否超限并可视化布局

关于磁盘整数分区规划

磁盘整数分区规划是一款纯前端的轻量工具，帮你把一块磁盘按整数 GB 来划分分区。只需填入磁盘实际总容量（GB）和每行「名称 大小GB」的分区清单，工具会校验是否超出容量、按所选策略处理剩余空间，并以可视化条形图和明细表格呈现最终布局，还能一键导出方案文本。整个过程在浏览器本地完成，不联网、不上传任何数据。

使用步骤

  1. 在「磁盘总容量（GB）」填入磁盘的实际可用容量。注意厂商标称容量通常大于系统识别值（如 1TB≈931GB），应以系统显示值为准。
  2. 在「分区方案」中按行填写分区，每行格式为「名称 大小GB」，大小必须是正整数，例如「系统C 120」。
  3. 选择「未分配空间处理」策略：保留未分配 / 并入最后一个分区 / 均摊到前面的分区。
  4. 点击「规划分区」，查看条形布局、明细表格与汇总；需要留存时点「下载」导出方案文本。

常见错误

用标称容量当总容量

标称 1TB 不等于系统 931GB，直接用 1024 会让规划偏大、实际装不下。应以系统识别的容量填写。

把剩余空间一次分满

留一点未分配空间便于后续调整或对齐；一次性分满反而后期难以扩展。

大小写成小数或带单位

本工具只接受整数 GB，写「120.5」或「120GB」都会报错，请只填纯数字。

常见问题

为什么提示要按实际容量而不是标称容量？

厂商标称的 1TB 按 1000 进制，系统按 1024 进制计算，1TB 硬盘通常只显示约 931GB。直接用 1024 规划会导致偏大、实际装不下，应以系统识别的容量填写。

余数「均摊」是什么意思？

当分区总和不等于磁盘容量时，选「均摊」会把多出的整数 GB 从第一个分区开始每个 +1GB 依次分配，直到分完，避免留下零散未分配空间。

我的数据会传到服务器吗？

不会。工具完全在浏览器本地计算，符合 ToolHub 本地执行、数据不出本机的承诺，断网也能用。

这个工具能直接给硬盘分区吗？

不能。它只做容量规划与整数分配的可视化，不读取也不改写你的磁盘。实际分区请在 Windows 磁盘管理、macOS 磁盘工具或分区软件中，按规划好的方案执行。

支持 GPT、MBR 或 4K 对齐吗？

不支持。本工具只关心「每个分区占多少整数 GB」，不涉及分区表类型（GPT/MBR）和 4K 对齐等底层细节；这些请在你使用的分区工具里设置。
