图片转 PDF

多张图片合成一个 PDF，A4 或适应图片，本地生成不上传

关于图片转 PDF

图片转 PDF 是报销、投稿、归档的高频动作：一堆发票照片要合成一个文件上传、证件扫描件要按页整理、作品集要发给对方而不被压缩。本工具在浏览器内用 pdf-lib 生成 PDF，每张图片一页，可选 A4 页面或「适应图片」，图片本身不上传，几十兆的扫描件也不受服务端大小限制。

使用步骤

  1. 点「选择图片」，按住 Ctrl 或 ⌘ 多选，选择顺序就是页面顺序
  2. 选择页面尺寸：要打印选 A4，要电子归档选「适应图片」
  3. 按需要设置页边距，无边距适合满页图片，10mm 适合打印留白
  4. 点「生成 PDF」，确认页表里每张图都按预期排好了
  5. 点「下载 PDF」保存到本地；文件只在内存里，刷新页面就没了

常见错误

直接拖 iPhone 的 HEIC 照片

HEIC 是苹果的默认格式，浏览器无法解码，会全部被跳过。先在手机「设置 → 相机 → 格式」选「兼容性最佳」，或用系统分享面板导出为 JPG。

竖拍照片生成后横躺

手机拍照会把方向写在 EXIF 里，PDF 不读取这段信息，页面就按原始像素方向呈现。转之前先用图片工具把方向摆正，或拍摄时保持横向构图。

期待扫描件能搜索文字

本工具只把图片贴进 PDF 页面，不做 OCR。生成的 PDF 是图片型，无法选中文字。需要可搜索的扫描件，请先用 OCR 工具（如 tesseract）识别后再合并。

用「适应图片」模式处理长截图

超长截图（如一整页网页）在「适应图片」模式下页面会非常高，超过 PDF 单页上限会直接报错；即便没有超限，打印也会被切成很多段。这类图更适合用 A4 模式或先切分。

常见问题

支持哪些图片格式？

PNG 与 JPG/JPEG。WebP、GIF、HEIC（iPhone 默认格式）、TIFF 需要先转换：可以先用本站的「图片格式转换」转成 PNG 再来。工具会逐张提示哪些文件被跳过，其余正常生成。

生成的 PDF 很大，怎么变小？

PDF 内嵌的是原始图片数据，不做重新压缩，所以体积基本等于所有图片之和。要减小体积，先用「图片缩放」把长边压到 1600–2000 像素，或用「图片压缩」降低质量，再转 PDF。

能调整页面顺序或删除某一页吗？

可以在生成前按顺序重新点选文件；生成后如果只想保留部分页面，用「PDF 合并拆分」的提取模式按页码抽出即可。

纸张大小和方向能调吗？

能选 A4、Letter 等常见尺寸，也能让页面跟随图片原始比例。跟随原图的好处是不产生白边，坏处是每页尺寸不一，打印时会各自缩放。要打印装订就固定 A4 并选「适应页面」。

手机拍的照片方向不对、旁边有白边？

方向问题来自 EXIF 里的旋转标记，多数情况下会自动校正。白边是因为照片比例和纸张比例不匹配——选「跟随图片比例」就没有白边，选固定纸张则会自动留白。要彻底干净，先用「图片裁剪」把比例裁成和纸张一致。
