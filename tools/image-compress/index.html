图片压缩

在浏览器本地压缩 JPG/PNG/WebP，图片不上传服务器

关于图片压缩

图片压缩是在肉眼几乎看不出差别的前提下，降低图片文件体积的处理。常见做法是降低量化精度（有损压缩）或优化编码参数（无损压缩）。有损压缩对照片类图片效果最好，通常质量 70-80 就能把体积减半；无损压缩更适合图标、线条图和需要保留像素精度的截图。

使用步骤

  1. 选择或拖入要压缩的图片（JPG / PNG / WebP）
  2. 拖动质量滑杆，右侧实时显示压缩后体积与预估画质
  3. 需要统一尺寸时先配合缩放工具处理，再压缩
  4. 点击下载，直接得到压缩后的文件

常见错误

二次压缩反而变大

已经被微信、QQ 或图床压过的图，内部编码已接近极限，再次有损压缩会重新量化，体积可能不降反升。

质量拉太低去追小体积

质量低于 40 后文字边缘会出现振铃和色块，压缩率提升却有限。截图类建议 60-70，照片类 75-80 是平衡点。

忽略格式选择的差异

需要透明的图不要转成 JPEG；要兼容旧浏览器时 WebP 不是万能解，准备一份 PNG 兜底。

常见问题

压缩后图片会不会上传到服务器？

不会。本站使用浏览器 Canvas API 在本机完成编码，图片数据从头到尾都没有离开你的设备，可以放心处理含客户信息的截图。

为什么 PNG 压缩后体积几乎没变？

PNG 是无损格式，质量参数对它无效。要明显减小体积，应该转成 JPEG 或 WebP，或者先用调色板量化。
