PDF 合并拆分

多个 PDF 本地合并、按页码提取、按页数拆分，文件不上传

关于PDF 合并拆分

PDF 合并拆分是把多个文档按需要重新组织的日常操作：三份报告合成一份发送、从长篇合同里抽出签字页、把扫描册子按页分发。这些处理的共性是——文件内容敏感，不值得为了两页 PDF 上传到陌生网站。本工具基于开源 pdf-lib 在浏览器内完成全部操作：合并按选择顺序拼接多个文件；提取按页码范围（如 1,3,5-8）抽出若干页生成新文件；拆分按固定页数把一个文件切成多份。原文件不会离开你的设备，也没有页数、大小或文件次数的限制（受本机内存约束）。

使用步骤

  1. 选择操作模式：合并、提取页面或拆分
  2. 合并模式：按住 Ctrl / ⌘ 多选若干 PDF，选择顺序就是合并后的顺序
  3. 提取模式：单选一个 PDF，填写页码范围（1,3,5-8 这种格式，留空表示全部页面）
  4. 拆分模式：单选一个 PDF，设置每份页数（填 1 即逐页拆分）
  5. 点击「开始处理」，完成后点对应的下载按钮保存结果

常见错误

页码范围从 0 开始数

人类数页码从 1 开始，但程序里从 0 开始。本工具已按人类习惯处理——输入 1 就是第一页。如果结果比预期少了首页，检查是不是把「1」误写成了「0」。

合并顺序按文件名排

多选文件的顺序以选择时的点击顺序为准，不是文件名排序。想按 1、2、3 合并，就按这个顺序点选；选乱了可以删除后重来，无需重新打开页面。

期望保留书签和目录

pdf-lib 复制的是页面内容，原文档的书签大纲不会带入新文件。合并长篇文档后需要目录的话，建议在合并后用支持书签的工具补建，或合并前与原文档一并归档。

扫描件文字无法搜索

本工具只做页面级的合并与拆分，不做 OCR。扫描件合并后仍然是图片型 PDF，无法搜索文字；需要可搜索版本请先用 OCR 工具（如 tesseract）处理再合并。

常见问题

合并会改变原文件的内容吗？

不会。合并只是把各文件的页面按顺序复制到一个新文档中，页面内容、尺寸、方向保持不变。需要注意 pdf-lib 的限制：书签、表单域、部分批注和附件不会带入新文件，只保留可见的页面内容。

加密的 PDF 能处理吗？

不能。带打开密码的 PDF 需要先解密（用阅读器打开后另存为无加密文件），带权限限制但能打开的 PDF 通常可以直接处理。工具遇到加密文件会给出明确提示。

支持多大的文件？

取决于本机内存。日常几十兆的文档没有问题；超过几百兆的扫描件建议分批处理。所有解析和生成都在本机进行，没有服务端的体积限制，但浏览器标签页的内存上限是真实存在的。
