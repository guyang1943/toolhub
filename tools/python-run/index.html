Python 运行器

浏览器内跑 Python（Pyodide WASM 沙箱），代码不出本机

关于Python 运行器

Pyodide 把 CPython 编译成 WebAssembly，让完整的 Python 解释器跑在浏览器里。它支持标准库和一部分科学计算包（numpy、pandas 等），适合验证代码片段、教学演示、以及在无法安装环境的机器上做临时计算。代价是首次加载需要下载较大的运行时。

使用步骤

  1. 首次打开等待运行时下载（约 10MB，同会话内只加载一次）
  2. 在编辑器输入代码，需要第三方包时先 import 再自动安装
  3. 点击运行，stdout 与报错显示在下方输出区
  4. 处理数据时把 CSV/JSON 内容作为字符串粘进代码，沙箱读不了外部地址

常见错误

把沙箱当完整环境

没有文件系统、网络和部分 C 扩展。依赖 requests、socket 的代码在沙箱里跑不了，先确认代码只依赖纯 Python 部分。

首次加载误判为卡死

运行时下载期间页面无响应是正常的，等进度走完再操作；刷新会重新下载，耐心等一次即可。

大数据集直接硬编码

几万行的数据粘进代码字符串会让编辑器卡顿。先在外部做好抽样，沙箱里只验证逻辑。

常见问题

能访问本地文件或网络吗？

不能，这是沙箱的安全边界。需要外部数据时，请把内容粘贴进代码作为字符串常量。

为什么第一次运行特别慢？

需要下载约 10MB 的解释器运行时并初始化。同一次会话内后续运行几乎是瞬时的，刷新页面后需要重新加载。
