Placehold · 官方在线版

一行 URL 生成占位图，开发测试利器

它解决什么问题

Placehold 用一行 URL 生成占位图：`/600x400/2563eb/fff?text=Hero` 就是一张 600×400、蓝底白字的图，尺寸、颜色、文案全在 URL 里。相比 Picsum 的照片占位，它更适合「需要标注尺寸和用途」的线框图和设计稿。

三个典型使用场景

  1. 设计稿里给每个区块放带尺寸文字的占位图，评审时一眼看清布局
  2. 前端 demo 里给 banner 位放纯色占位，避免图片加载干扰布局验证
  3. 截图对比测试里用固定尺寸纯色图，减少变量

和 ToolHub 本地工具怎么配合

图片缩放：需要把已有图片统一成多个尺寸规格时，站内批量缩放更灵活（本地工具，文件不上传）

图片转 Base64：占位图内联进 HTML 邮件时，用 Base64 可以避免外部图片被拦截（本地工具，文件不上传）

同类可替代方案

  • Squoosh —— Google 出品的图片压缩，对比预览效果极佳
  • Picsum Photos —— 占位图服务，开发测试用假图一键生成
  • Tesseract.js OCR —— 浏览器本地图片文字识别（OCR）官方演示

使用时要注意什么

纯色矩形，无法模拟真实照片的视觉重量；服务可用性无保证，正式项目应自行生成本地占位图。

常见问题

Placehold 是免费的吗？

Placehold 是开源项目，采用 MIT 许可证，官方在线版可以免费使用，不需要为基本功能付费。ToolHub 只做收录与说明，不代管你的数据，也不提供账号或存储服务。

Placehold 适合什么场景？

最常见的是这几种：设计稿里给每个区块放带尺寸文字的占位图，评审时一眼看清布局；前端 demo 里给 banner 位放纯色占位，避免图片加载干扰布局验证；截图对比测试里用固定尺寸纯色图，减少变量。判断标准很简单——如果你现在正为了这件事装一个几百 MB 的桌面软件，先用它试一次。

它和 ToolHub 的本地工具有什么区别？

ToolHub 的本地工具把代码放在你的浏览器里执行（WebAssembly 或原生 JS），文件不经过服务器；Placehold 由项目作者维护，数据在其服务器或你的浏览器中处理，具体取决于项目实现，使用前建议先看对方的数据政策。需要「绝对不上传」时可以改用站内同类工具。

用 Placehold 有什么限制？

纯色矩形，无法模拟真实照片的视觉重量；服务可用性无保证，正式项目应自行生成本地占位图。
