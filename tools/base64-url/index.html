Base64 / URL 编解码

Base64 与 URL 编码互转，支持中文

关于Base64 / URL 编解码

Base64 是把二进制数据映射成 64 个可打印字符的编码方式，常用在只能传输文本的场景，比如邮件、JSON 字段、URL 参数。URL 编码（percent-encoding）则是把空格、中文、& ? 等特殊字符转成 %XX 形式，避免破坏 URL 结构。两者都是编码，不是加密——任何人都能还原。

使用步骤

  1. 选择模式：Base64 编解码、URL 编解码或 Data URI 处理
  2. 粘贴原文或密文，中文内容勾选 UTF-8 处理
  3. 核对输出结果，复制到目标位置
  4. 批量场景可一次性粘贴多行，按行分别处理

常见错误

把 Base64 当加密

解码只需要一秒。任何“看起来乱码就觉得安全”的想法都危险，敏感数据请用真正的加密算法。

URL 编码不完整

只转义空格不转义 & 和 #，链接照样会断。整个查询串都要编码，服务端再解码。

编码后当作二进制直接比较

Base64 输出依赖填充和换行约定，不同实现可能差在行尾换行；比对内容前先统一格式。

常见问题

为什么用 btoa() 处理中文会报错？

btoa 只接受 Latin-1 字符。中文需要先按 UTF-8 转成字节数组再编码，本工具已内置这个处理。

Base64 能用来加密数据吗？

不能。Base64 是公开的可逆编码，没有任何密钥，只适合传输，绝不能当作密码或敏感数据的保护手段。
