Filee 测评：一个月 2 万星的拖拽转换器，能替掉在线转换站吗

一个 2026-09-29 才建仓的 C# 项目，一个月拿到 2 万星，卖点只有一句「文件不出这台电脑」。把 255 种格式的转换塞进一次拖拽，代价是 150MB 安装包和「必须装软件」。值不值，看你转文件的频率。

结论：常做格式转换的人值得装——图片、Office、PDF、音视频、电子书、压缩包一次包完，全程离线。只是「PDF 转 Word 保留版面」这类难题它还没解，遇到复杂排版仍要人工返工。

怎么测的：依据 KnifeLemon/Filee 仓库 v2.2.0（2026-10-28）的 README、Release 资产清单、官网 FAQ 与公开 issue 核实，并对照站内同类本地工具的实际表现。未在本机安装桌面程序。

对比项

Filee（桌面程序 · 隐私：完全本地）

优势：255 种格式 / 18 类，其中 147 种装完即用，其余靠可选引擎；按住 Ctrl 拖文件到光标处，格式圆环直接展开，不用开主窗口；批量并行转换，单个文件失败不中断其余；Word / Excel / PPT / 韩文 HWP 不装 Office 也能转；命令行 filee convert 与 filee watch 可挂文件夹自动转

短板：Windows 安装包 150MB，体积主要来自内置与可选引擎；视频音频首次使用要另外下 FFmpeg 引擎；macOS 13+ 仍是 preview，且未公证；「PDF 转 DOCX 保留版面」在 issue 里被反复提，目前做不到；Windows on ARM 还没支持

本站 · 图片转换 / 图片转 PDF（浏览器本地 · 隐私：完全本地）

优势：零安装，打开网页就能转，不用下 150MB；图片格式互转与转 PDF 覆盖了最高频的那部分需求；和压缩、裁剪、去 EXIF 串成一条链，中间不用落盘

短板：只覆盖图片与 PDF，视频、Office、电子书都不在范围内；一次处理量受浏览器内存限制

上传型在线转换站（常见模式）（上传到服务器 · 隐私：需上传）

优势：什么都不用装，格式清单看着很全；冷门格式的支持面往往比免费桌面软件宽

短板：文件要离开设备，保留多久、谁看过都不可控；限大小、限次数、广告和排队是常态

怎么用

装（Windows）

  1. 从 Releases 下 Filee-2.2.0-win-Setup.exe；不想安装就用 win-Portable.zip 解压后直接跑 Filee.exe
  2. 安装过程中可勾选「加入资源管理器右键菜单」「开机启动」「命令行 filee」，按需选
  3. Windows 10 老系统上如果双击没反应也没报错，通常是系统缺 .NET 需要的组件——先装系统更新，或只对 Filee 关掉硬件强制栈保护

转一个文件

  1. 在资源管理器里选中文件，按住 Ctrl 拖出来（macOS 是 Option）
  2. 光标处展开格式圆环，只列出这个文件能转成的目标格式
  3. 拖到目标格式上松手，圆环变成进度环，完成后新文件出现在原文件旁边
  4. 按 Tab 或滚轮把圆环翻到背面：裁剪、旋转、灰度、去背景、合并成一个 PDF、打包成一个 ZIP

批量与文件夹

  1. 一次选中多个文件拖进去，会并行转换，单个失败不会中断其余
  2. 也可以右键菜单「Convert with Filee」，或从「发送到」进入
  3. 挂文件夹自动转：filee watch D:\Inbox --to pdf --move-originals，新落进文件夹的文件自动转换、原件挪走

命令行（脚本 / 定时任务）

  1. filee convert photo.heic --to jpg
  2. filee convert *.png --to webp --quality 80 -o converted
  3. 支持 JSON 输出与退出码，可直接接进批处理或计划任务

详细解读

先说它为什么火。Filee 的仓库 2026-09-29 才建，到 11 月初 20,183 星、1,235 个 fork，Trendshift 的 C# 周榜第一。原因不是功能多——格式转换器满地都是——而是它把交互做没了：按住 Ctrl 把文件从资源管理器拖出来，光标处直接展开一圈格式，松手就开始转，结果落在原文件旁边。整个流程没有主窗口。

数字上有个细节值得记一笔：GitHub 仓库描述写 263 种格式，README 写 270 种，官网 FAQ 写 255 种（其中 147 种装完即用）。三个地方三个数字，不是造假，是文案追不上迭代速度——这项目一个月发了二十多个版本。引用时以官网那个 255 为稳妥，因为它连「哪些格式需要额外引擎」都逐项标了出来。

架构上它做对了两件事。一是内置引擎不依赖外部软件：Word、Excel、PPT 和韩文 HWP 都直接转，机器上装了 Office 也不用。二是可选引擎按需下载：FFmpeg、LibreOffice、Calibre、Ghostscript、Pandoc 只在你真要用某类格式时才提示。150MB 的安装包买的就是「装好之后彻底离线」这件事。

短板在 issue 区写得很直白，而且不是「新项目总有的那种」短板。中文用户反复提的是 Word 转 PDF 的排版：1.5 倍行距、小四字体这类中文排版规则还原不准；另一个高频请求是「PDF 转 DOCX 要保留表格、字体、页面结构」——这件事连商业软件都做不好，Filee 目前的答案是做不到。另外还有 Setup.exe 在部分 Windows 上装不上、Windows on ARM 没支持。

所以它的位置很明确：日常格式转换（HEIC 转 JPG、PNG 转 WebP、图转 PDF、Word 转 PDF、MP4 转 MP3、RAR 转 ZIP）它做得又快又干净，而且不用把文件交给任何人；需要保版面的 PDF↔DOCX、需要精细排版还原，它现在接不住。这也是本站一直的观点——转换这件事，边界比格式数量重要。

选型一句话：一个月转不了三个文件，别装，用浏览器里的本地工具就够；每周都在转、还经常碰视频和 Office 文件，这 150MB 值得。
