图片处理全流程

压缩、缩放、转 Base64、生成二维码——从拿到图到能用图，一条链路走完

专题说明

做内容时图片处理占了大量时间：截图太大发不出去、头像尺寸不合规、图标要内联进 CSS、链接要做成二维码。这组工具的共性是「处理完就能直接下载/复制」，不需要打开 PS 或在线图床，而且图片始终留在本机。

包含工具（按建议顺序）

  2. 图片缩放
  3. 图片转 Base64
  4. 二维码生成
  5. 颜色格式转换

常见问题

为什么压缩后反而变大了？

原图本身已经被压过（比如微信传过的图），再压会重新编码导致体积上升。可以降低质量到 50-60 试，或改用 WebP。

透明背景保不住？

JPEG 不支持透明通道，需要透明的图请保留 PNG 或输出 WebP。
