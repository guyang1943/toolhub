专题说明

写作的流程通常是：打草稿（Markdown 预览）→ 卡字数（字数统计）→ 修改稿（文本对比）→ 整理素材（去重排序）。这组工具覆盖从起草到定稿的全过程，都不需要注册、不收集内容，写完直接复制走人。投公众号、知乎或内部文档，格式一次搞定。

包含工具（按建议顺序）

  1. Markdown 预览
  2. 字数统计
  3. 文本对比
  4. 文本去重排序
  5. 命名风格转换

常见问题

中文字数为什么和 Word 不一样？

统计口径不同：中文按「字」计（含标点），Word 按「字符数」计。本工具两者都给，投不同平台时按对方要求的口径看对应数字。

Markdown 表格对不齐

表格第二行的分隔线（|---|）才是表格生效的关键，前后留一个空行；预览里样式以渲染结果为准，源码里的空格不影响显示。
