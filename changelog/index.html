v3.7 · 新增图片裁剪 / 文件哈希校验 / CSV 选列三个本地工具

2026-10-27

  • 三个新工具入库，工具总数 94 → 97：img-crop（拖框选裁剪，等比锁定 + 圆角 + PNG/JPEG/WebP）、file-hash（MD5/SHA-1/SHA-256/SHA-512 与官方校验值比对）、csv-columns（选列、拖动排序、按列值过滤后导出）
  • file-hash 四种算法全部手写增量实现：crypto.subtle 没有 MD5，且必须一次吃下整个 ArrayBuffer（1GB 文件先占 1GB 内存）。自己写的好处是能分片读、边读边出进度，实测 30MB 文件 MD5 0.26s / SHA-1 0.62s / SHA-256 0.74s / SHA-512 1.02s
  • MD5 手写最常错的两处都钉住了：padding 的长度位是 64 位小端（写成 32 位在 >512MB 才暴露）、末轮寄存器顺序。空串与 abc 两个公开向量同时锁死这两类错误，另与 node:crypto 交叉验证 9 组输入（含 55/56/64 字节的 padding 临界值与 300KB 随机数据）
  • csv-columns 用引号状态机而不是 split：引号内的逗号、换行、双写引号都在状态机里处理，导出时按「原本是否带引号」还原风格。a,,c 是三列而不是两列——中间那个空字段被压掉是最常见的手写 bug
  • img-crop 越界分两档：部分越界收缩到边缘并提示收到多少像素，起点本身在图外直接报错并给出图片真实尺寸，不会产出 1px 空白图。JPEG 导出先铺白底，否则圆角之外是黑的
  • 补三条工具页样式（外包方无权改 assets，收包后补的）：预览画布限高 42vh（800×2000 的长截图会撑到 630px，把坐标框整个推出视野）、CSV 列标签容器限高 112px 滚动（40 列的报表会换五六行）、.msg-warn 与 --warn 变量（之前只有 .msg-ok，提醒类提示在 exif-strip 和三个新工具里都是裸文本）
  • 修两处深色模式缺陷：csv-columns 的列标签把颜色内联写死成 #fff / #eff6ff，深色主题下是一排白块；img-crop 的提示文字硬编码 #6b7280，深色下对比度只有 3.6:1。两处都改成 CSS 变量，体检复检 0 问题
  • file-hash 的 accept 补上压缩包：原本只列了安装包与镜像，而开源项目的发布包绝大多数是 .zip / .tar.gz——那才是校验值最常见的对象。同时把「不认识的文件不硬推」的反例从 a.zip 换成 a.xyz（zip 现在是能被认出的文件了），并补两条正向断言：.zip 与 .iso 必须路由到哈希工具
  • 功能测试 161 → 206（新增 45 条：img-crop 11 / file-hash 15 / csv-columns 17 / 拖放路由 2）
  • 首次走完整外包流程交付：任务包 docs/taskpacks/TP4-new-tools.md 派给低成本模型，在 git archive 导出的隔离快照里完成，收包后用独立脚本复核（哈希与 node:crypto 逐位比对、CSV 状态机自造边界、几何纯函数），再合并验收
