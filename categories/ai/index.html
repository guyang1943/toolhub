🤖 AI 与本地模型工具

把模型装在自己机器上：本地推理、自托管服务、编辑器里的编码助手——先看清它跑在哪，再问提示词去哪。

工具分类 / AI
这一类和其他分类有个根本区别：工具本身不处理数据，处理数据的是它背后那个模型，而模型可能跑在你这台机器上，也可能跑在厂商的服务器上。所以每条都先回答两件事——「跑在哪」和「你的提示词会去哪里」。这两件事决定了它对你是不是真的隐私友好。只收能说清执行位置的项目：纯云端、必须注册才能用的服务不进这一栏，它们属于资源库。

怎么挑

  • 先看「跑在哪」：浏览器 / 需安装客户端 / 需自行部署 / 编辑器扩展，四条路门槛差很远——浏览器零安装但吃显存，自部署最灵活但要有服务器。
  • 再看要不要 Key：本地客户端（Ollama / GPT4All / AnythingLLM）装好自带模型；界面类（Open WebUI / Dify / Cline）本身不含模型，得接本地端点或填厂商 Key。
  • 最后看提示词去哪：接本地模型就是不出机器，填了厂商 Key 就是发给那家厂商。这是用云模型的代价，不是工具的错，详情页逐条写清了。
  • 硬件先算账：7B 模型约需 8GB 内存，13B 要 16GB；文生图要独立显卡、显存 8GB 起步。跑不动就先从浏览器版试水。

常见问题

本地跑模型真的不上传任何东西吗？
模型权重第一次要从网上下载，那一步是下载不是上传。之后推理在本机完成，提示词不出机器——除非你主动切到云端模型，或者接的是厂商 API。
没有独立显卡能用吗？
能。7B 级别的模型在 16GB 内存的 CPU 上可以跑，只是慢，每秒几个字到十几个字。浏览器版（WebLLM）靠 WebGPU，集显也能跑小模型；文生图对显卡要求最高，没有独显建议先试云端。
这些和站内的本地工具有什么区别？
站内工具是「打开网页就完事」的一次性处理，代码在你的浏览器里跑；这一类要装软件或起服务，换来的是一台常驻的模型。共同点是不用看别人服务器的脸色。
